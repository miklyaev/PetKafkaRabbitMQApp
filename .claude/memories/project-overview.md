# Обзор проекта

Проект представляет собой систему управления задачами и проектами, похожую на Jira. Он включает в себя как серверную часть (ASP.NET Core), так и клиентскую часть (React).

## Основные компоненты:
- Серверная часть: ASP.NET Core Web API
- Клиентская часть: React.js приложение
- База данных: Entity Framework Core с SQL Server
- Docker для контейнеризации

## Функциональность:
- Управление задачами (Tasks)
- Управление проектами (Projects)
- Управление пользователями (Employees, Leaders, Executors)
- Комментарии к задачам
- Временные записи (Time Entries)
- Цели (Goals)

## Технологии:
- ASP.NET Core 6.0
- React 18
- Entity Framework Core
- SQL Server
- Docker
